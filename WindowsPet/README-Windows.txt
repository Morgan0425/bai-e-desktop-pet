银灰发少年桌宠 Windows 版
======================

系统要求：Windows 10 或 Windows 11

启动：双击“Start-Silver-Pet.bat”

操作：
- 鼠标悬停：疑问动画，持续悬停可能害羞
- 按住拖动：提起并移动；左右偏摆跟随鼠标方向
- 松开：掉落、着地并恢复
- 快速连续点击3次以上：生气
- 侧边按钮：吃饭、睡觉、坐下
- 右键角色：隐藏或退出
- Ctrl + Alt + H：全局隐藏/显示
- Ctrl + Alt + Q：全局退出

若 Windows 弹出安全提示，请确认压缩包来源可信后再运行。本程序不会联网，
不会安装系统服务，也不会修改注册表。
